About the Project

LifeLink is a student-developed Organ Donor Registration System prototype that demonstrates how digital technology can support the organization of donor pledge records. It provides sample donor registration, record searching, registration status management, and basic statistics through a simple, user-friendly interface. This project is intended for academic demonstration and is not an official organ donor registry.

Information & FAQ

Is this an official registration service?

No. This is an academic demonstration and cannot register a real organ donor.

Who determines eligibility?

Eligibility and donation procedures must be discussed with authorized medical professionals and official donation services.

Does this website connect to the C program?

Yes. LifeLink supports file-based integration with the C Organ Donor Registration System. Sample donor records can be exported as a CSV file from the website and manually imported into the C program. Automatic real-time synchronization is not available.

Can a registration be reactivated?

Yes. An inactive sample record can be reactivated using the Reactivate button.

Are sample records saved?

Sample records are stored in the browser's local storage and normally remain available after refreshing the page in the same browser. Clearing browser data may remove them.
